# تطبيق عملاء ماركت المعداوي

تطبيق تسوّق وطلب منتجات ماركت المعداوي، مع عرض منتجات المحلات الشريكة، السلة، العناوين، الطلبات والإشعارات. يعمل كواجهة ويب، وله نسخة Android مبنية باستخدام Capacitor.

## التقنية المستخدمة

- React وTypeScript وVite
- Tailwind CSS وshadcn/ui
- Capacitor لنسخة Android
- Supabase للخدمات الخلفية وFirebase لإشعارات الأجهزة

## التشغيل محليًا

يتطلب Node.js وnpm. بعد استنساخ المستودع:

```bash
npm ci
npm run dev
```

لبناء واجهة الإنتاج:

```bash
npm run build
```

لمزامنة نسخة Android بعد إعداد Android SDK:

```bash
npm run android:sync
```

إعدادات الخدمات والمفاتيح الخاصة يجب أن تبقى في ملفات بيئة أو خزائن أسرار مناسبة، ولا تُحفظ في المستودع. نشر نسخة Android على Google Play يحتاج حزمة موقّعة بمفتاح رفع محفوظ خارج Git، مع زيادة `versionCode` في كل إصدار.
